# Adaptive Learning Video Generator Using Generative AI

## About the Project
The Adaptive Learning Video Generator is a Streamlit-based application that generates personalized educational video content using Generative AI. Users can enter a topic, select a learning level, and choose a video duration to generate educational content.

## Features
- AI-based educational script generation using Gemini API.
- Customizable learning level and video duration.
- Text-to-speech narration using gTTS.
- Automatic image retrieval for educational content.
- Video creation using MoviePy.
- Interactive interface built with Streamlit.

## Technologies Used
- Python
- Streamlit
- Google Gemini API
- gTTS
- MoviePy
- HTML and CSS

## Project Workflow
1. Enter a learning topic.
2. Select the desired learning level and video duration.
3. Generate an educational script using Gemini API.
4. Convert the script into speech using gTTS.
5. Retrieve relevant images for the topic.
6. Combine images and narration to create the educational video using MoviePy.

## How to Run
1. Clone the repository.
2. Install the required dependencies.
3. Configure your Gemini API key.
4. Run the Streamlit application.
